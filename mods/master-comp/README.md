# master-comp

Bus compressor on the **analog master** of the Syntakt.

## Use

FX track → **SYN** page:

| Knob | Range |
|---|---|
| THR | threshold, −60 … 0 dB |
| ATK | attack, 0.1 … 100 ms |
| REL | release, 10 ms … 2 s |
| MUP | makeup, 0 … +24 dB (capped by the master volume range) |
| RAT | **OFF**, 1.5:1, 2:1, 3:1, 4:1, 6:1, 8:1, 16:1, 20:1 |
| GR | gain-reduction meter (read only): full bar = no reduction, empties down to −18 dB |
| COMP | **ON/OFF** switch for A/B comparison; keeps RAT and the other settings. Not saved, starts ON |
| DRIVE | unchanged |

Values are shown in real units (`-30dB`, `25ms`, `4:1`).
Settings are saved **per pattern** (with the kit), or **globally** when *SYN global* is on. Existing projects load with the compressor **OFF**.

## How it works

- **Feed-forward VCA compressor.** Detects on ADC 6/7 (analog mix bus *before* the master VCAs), applies gain by scaling the master VCA control voltages (CV 35/36), once per audio block (~1.5 kHz).
- **Detector:** block peak (32 samples) → log2 → threshold/ratio → peak-hold with release → attack smoothing, then makeup and exp. Curves match the Digitakt mk1 compressor; all tables are generated from formulas in `dsp.py`. Since v0.8.1 the hold and attack filters are solved over the block in closed form (r³², a³² and one cross term, recomputed only when a knob moves) instead of per sample: the gain was already applied once per block, and the result differs from the per-sample detector by 0.03 dB median, ~1 dB at worst (slightly more reduction on high frequencies).
- **UI:** ids 262-268 are native MIDI CC Select descriptors, not globally free. The mod captures their stock descriptor/object state and routes them to the compressor only while the FX track owns its SYN page; moving to a MIDI track restores the captured state before that page draws. Storage: 4 unused words of the external-mixer block of the kit.
- **Text:** one formatter per id (128-entry tables generated by make_patch.py from the dsp.py formulas). The scoped UI helper runs at the generic SourcePage draw boundary, never in the audio interrupt.
- **Cost per audio block:** ~100 instructions off, ~600 on (v0.8.0: ~2 000); constants are recomputed only when the stored values change. Regression test in `tests/test_master_comp.py`.
- No dry/wet: impossible on a VCA.

Details: [docs/audio-path.md](../../docs/audio-path.md), [docs/ui-parameters.md](../../docs/ui-parameters.md).

## Known side effect

Toggling *global* for the **external input** mixer also copies these settings (they share that kit block).

## Build / test

```sh
python mods/master-comp/make_patch.py      # [--thr --atk --rel --mup --rat --no-drive-knob]
python -m pytest tests/test_master_comp.py
```
